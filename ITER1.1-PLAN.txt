────────────────────────────────────────

1. ES↔HU MINDKÉT IRÁNY

   Jelenlegi állapot: csak ES→HU (spanyol szó → magyar fordítás)

   Teendő:
   - Onboarding: ES→HU és HU→ES is választható legyen
   - supportedPairs bővítés: ['es','hu'] és ['hu','es']
   - words.ts: már tartalmaz mindkét nyelvet (es + hu), irány-függő megjelenítés
   - Flashcard: ha ES→HU → spanyol szó felül, magyar alul
                 ha HU→ES → magyar szó felül, spanyol alul
   - Gépelős: célnyelvi szót kell begépelni

2. GÉPELŐS KÁRTYA TÍPUS

   Új kártya mód a sima reveal mellé:
   - Spanyol szó megjelenik felül
   - Alul TextInput mező → user begépeli a magyar fordítást (vagy fordítva)
   - Submit → összehasonlítás:
     - Helyes → zöld feedback + FSRS Good
     - Majdnem (1-2 betű eltérés, Levenshtein ≤ 2) → sárga, mutatja a helyeset + FSRS Good
     - Hibás → piros, mutatja a helyeset + FSRS Again
   - Kártyák keverése: ~50% flashcard reveal, ~50% gépelős (random)
   - Mobilon: billentyűzet automatikusan felugrik gépelős kártyánál

3. "PASSZÍV TANULÁS" FELIRAT ELTÁVOLÍTÁS

   - Tab neve: "Passzív" → "Tanulás" vagy egyszerűen nincs tab (csak 1 fő screen)
   - Header: "Passzív" → app név vagy semmi
   - Aktív tab marad placeholder ("Hamarosan")

4. APP NYELVE = TELEFON NYELVE (i18n)

   Expo Localization használata:
   - `expo-localization` csomag (Localization.locale)
   - Támogatott nyelvek iter1.1: Magyar (hu), Spanyol (es), Angol (en) fallback
   - i18n fájl struktúra:
     lib/i18n/hu.ts — magyar UI szövegek
     lib/i18n/es.ts — spanyol UI szövegek
     lib/i18n/en.ts — angol UI szövegek (fallback)
   - Érintett szövegek:
     - Onboarding: "Milyen nyelven beszélsz?" / "¿Qué idioma hablas?" / "What language do you speak?"
     - Gombok: "Jó/unom/újra" / "Bien/aburrido/otra vez" / "Good/bored/again"
     - "Koppints a fordításhoz" / "Toca para traducir" / "Tap to translate"
     - "Kész vagy mára!" / "¡Terminaste por hoy!" / "Done for today!"
     - Streak: "nap streak" / "racha de días" / "day streak"
     - Gépelős: "Írd be a fordítást" / "Escribe la traducción" / "Type the translation"
   - Settings-ben nyelvváltás opció (override rendszernyelv)

5. KÁRTYA NE UGORJON FEL REVEAL-KOR

   Probléma: kártyára koppintás → 3 gomb megjelenik alul → kártya felugrik,
   zavaró layout shift.

   Megoldás:
   - Gombok ("Jó/unom/újra") MINDIG foglalják a helyet (invisible placeholder)
   - Reveal-kor gombok láthatóvá válnak, de NEM tolják el a kártyát
   - Kártya pozíció fix marad, fordítás a kártyán belül jelenik meg
   - Technikailag: gombok `opacity: 0` → `opacity: 1`, nem conditional render
